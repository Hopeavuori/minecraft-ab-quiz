# Minecraft A/B -tietovisa (React + Vite + Tailwind)

## Nopein tapa käyntiin
1. Asenna Node.js LTS (https://nodejs.org/)
2. Pura tämä kansio ja mene sen juureen:
   ```bash
   cd minecraft-ab-quiz
   npm install
   npm run dev
   ```
3. Avaa selaimeen osoite, jonka Vite näyttää (yleensä http://localhost:5173).

## Build tuotantoon
```bash
npm run build
npm run preview
```

## Muokkaa kysymyksiä
Avaa `src/App.jsx` ja muokkaa `QUESTIONS`-taulukkoa.
